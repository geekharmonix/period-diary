# Period diary
An early browser prototype for recording menstrual period start dates. Open index.html in a browser. The app uses browser storage, has no accounts or network requests, and makes no medical predictions. File-based storage support varies by browser. This prototype was created with AI assistance.

## Volunteer walkthrough
Use fictional dates only. Add 1 January 2024, reload the page, and check the date appears. Add it again and check that only one entry appears. Remove the entry, then add 2 January 2024 as a correction. Remove the test entry and reload to check the empty state.
